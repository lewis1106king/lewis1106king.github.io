# 기체 연결

사이트에서 바로 연결합니다. 노트북에 따로 프로그램을 띄우지 않아도 됩니다.

## USB

수색 화면에서 **기체**를 고르고 **드론 연결 (USB)** 을 누릅니다. Chrome 또는 Edge(컴퓨터), Chrome 안드로이드(USB OTG)에서 포트를 고릅니다. 통신 속도는 57600을 먼저 보고, 신호가 없으면 115200을 봅니다. SiK 텔레메트리 라디오는 보통 57600, 비행 컨트롤러 USB는 115200입니다.

브라우저는 기체 위치를 읽어 같은 수색 화면에 올립니다. 구역을 그린 뒤 **경로 올리기**로 잔디깎기 임무를 보내고, **자동 수색**으로 자동 비행을 시작합니다. 일시정지, 복귀, 착륙은 그 화면에 있습니다. 시동과 이륙은 **시동 후 이륙**을 확인하고 GPS, 배터리, 연결이 맞을 때만 보냅니다.

아이폰 Safari와 Firefox에는 USB 직렬 연결이 없습니다. 그 경우에는 **폰 카메라**를 쓰세요.

## 이미 열려 있는 주소

BlueOS나 동반 컴퓨터가 MAVLink를 WebSocket으로 이미 열고 있다면, 그 주소를 입력하고 **주소 연결**을 누릅니다. 바이너리 MAVLink와 JSON 모두 받습니다.

## DJI

DJI 일반 소비자 드론은 브라우저에 바로 연결되지 않습니다. DJI Mobile SDK 앱이나 DJI Cloud API가 필요합니다. 이 사이트는 그 연결을 흉내 내지 않습니다.

## 고급: 예전 다리

mavlink2rest가 `http://127.0.0.1:8088` 에 있을 때만, 이 폴더에서 `node server.mjs` 를 실행할 수 있습니다. 기본 주소는 `ws://127.0.0.1:8777` 입니다. USB로 바로 연결되면 이 다리는 필요 없습니다.

`MAVLINK_REST`, `BRIDGE_PORT` 로 주소와 포트를 바꿀 수 있습니다.
