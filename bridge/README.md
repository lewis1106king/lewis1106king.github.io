# 기체 연결

사이트는 계정 없이 동작합니다. 실제 기체는 이 컴퓨터에서 다리만 띄우면 됩니다.

## 시뮬레이터

수색 화면에서 **시뮬레이터**를 고르고 **비행 시작**을 누릅니다. 기체가 없어도 지점마다 이동, 도착, 촬영, 확인이 이어집니다.

## 폰 카메라

드론에 폰을 고정하고 그 폰에서 **폰 카메라**를 고릅니다. 위치는 폰 GPS, 화면은 폰 카메라입니다. DJI Fly나 Pilot은 브라우저로 영상을 직접 보내지 않습니다. 그 경로는 RTMP나 WHIP 중계, 또는 DJI Cloud API가 필요해서 이 버전에는 없습니다.

## ArduPilot / PX4

1. 기체와 지상국이 MAVLink를 내보냅니다.
2. [mavlink2rest](https://github.com/mavlink/mavlink2rest)를 `http://127.0.0.1:8088` 에 띄웁니다.
3. 이 폴더에서 `node server.mjs` 를 실행합니다. 기본 주소는 `ws://127.0.0.1:8777` 입니다.
4. 수색 화면에서 **기체**를 고르고 그 주소를 연결합니다.

다리는 위치를 읽어 브라우저로 보내고, 다음 지점으로 갈 때 이동 명령을 전달합니다. 조종권과 안전장치는 기체와 지상국에 있습니다. 이 페이지가 프로펠러를 직접 돌리지는 않습니다.

`MAVLINK_REST`, `BRIDGE_PORT` 로 주소와 포트를 바꿀 수 있습니다.
